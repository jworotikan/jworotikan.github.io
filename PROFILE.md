**Technical notes for agents editing this repo:**
- **Single page.** `index.html` is self-contained, with hand-written CSS and vanilla JavaScript inline. There is no framework.
- **Tailwind CSS is used only in the "Engineering Approach" band (`#approach`).**
  - Classes use the `tw-` prefix and preflight is disabled, so Tailwind never overrides the hand-written CSS.
  - After changing any `tw-` classes, run `npm install` once, then `npm run build:css`. This regenerates `assets/css/tailwind.css`.
- **Icons:** Boxicons (local, `assets/vendor/boxicons`) across the site. Font Awesome 6 Solid (CDN) in the `#approach` band.
- **Font:** Plus Jakarta Sans (Google Fonts).
- **Interactive effects:**
  - left navigation rail;
  - ↑/↓ arrow keys jump between sections;
  - scroll progress bar;
  - reveal animations;
  - 3D tilt cards;
  - count-up numbers;
  - parallax hero.

  All effects respect `prefers-reduced-motion`.
- **Link previews:** Open Graph and Twitter tags point to `assets/img/og-image.png` (1200×630).
  - Image URLs must be absolute.
  - When the image changes, bump the `?v=N` cache-buster, then re-scrape it in the Facebook Sharing Debugger.
- **Visitor notifications:** the page includes an EmailJS + ipapi.co script that emails me when someone visits. When testing in a headless browser, block requests to `ipapi.co` and `emailjs` so tests do not send notification emails.
- **Git:** do not commit or push unless I ask.
